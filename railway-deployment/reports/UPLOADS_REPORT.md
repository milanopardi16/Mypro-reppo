# Uploads Report

## معماری بارگذاری فایل

پروژه از `multer` و ماژول `server/utils/upload.js` برای دریافت فایل‌ها استفاده می‌کند. فایل‌ها به صورت محلی در مسیر زیر ذخیره می‌شوند:

- `uploads/`

## جزئیات فنی

- محدودیت اندازه: **۱۰ مگابایت**
- فرمت‌های مجاز: `.pdf`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.doc`, `.docx`, `.xls`, `.xlsx`
- اعتبارسنجی شامل MIME type و magic bytes است.
- مسیر ذخیره‌سازی با `process.cwd()` و `uploads` ساخته می‌شود.

## خطرات روی Railway

- Railway از دیسک محلی موقت استفاده می‌کند. داده‌های ذخیره‌شده روی `uploads/` ممکن است پس از ری‌استارت یا بازسازی کانتینر از بین بروند.
- اگر اپلیکیشن به فایل‌های بارگذاری‌شده به‌طور دائمی نیاز دارد، این معماری باید اصلاح شود.

## توصیه‌ها

1. انتقال ذخیره‌سازی به سرویس Object Storage (مانند AWS S3، Backblaze B2 یا Google Cloud Storage).
2. یا استفاده از Volume پایدار Railway با پیکربندی مناسب.
3. ذخیره مسیر فایل در دیتابیس و نگهداری فایل‌ها در فضای ذخیره‌سازی خارجی.

## نتیجه

این بخش در حال حاضر **عملیاتی است اما برای تولید روی Railway دارای ریسک است**. بهترین راه این است که ذخیره‌سازی محلی را به یک راهکار پایدار ابری منتقل کنید.
