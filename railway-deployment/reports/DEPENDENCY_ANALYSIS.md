# Dependency Analysis

## وضعیت وابستگی‌ها

تمام وابستگی‌ها برای اجرای Express + React backend و frontend مورد استفاده قرار می‌گیرند.

## پکیج‌های عمده

| نام پکیج | نسخه | استفاده |
|---------|------|--------|
| `@prisma/client` | ^6.19.0 | ORM برای PostgreSQL |
| `express` | ^4.21.2 | فریم‌ورک بک‌اند HTTP |
| `react` | 19.2.4 | فریم‌ورک فرانت‌اند |
| `react-dom` | 19.2.4 | رندرینگ DOM React |
| `socket.io` | ^4.8.3 | ارتباط Websocket |
| `multer` | ^1.4.5-lts.2 | بارگذاری فایل |
| `jsonwebtoken` | ^9.0.3 | JWT authentication |
| `helmet` | ^8.2.0 | امنیت HTTP headers |
| `cors` | ^2.8.5 | کنترل CORS |
| `vite` | ^7.1.10 | بسته‌بندی و توسعه‌ی Vite |

## هشدارها و مسائل

- `multer@1.4.5-lts.2` منسوخ است و نسخه ۲.x پیشنهادی است.
- `uuid@8.3.2` و `uuid@9.0.1` منسوخ هستند و باید به uuid@11 برای CommonJS ارتقا یابند.
- `node-domexception@1.0.0` منسوخ است.

## نتیجه نهایی

تمام وابستگی‌های اساسی موجود و عملیاتی هستند. تنها نیاز به به‌روزرسانی شماری از پکیج‌های منسوخ‌شده‌ی اختیاری برای بهبود امنیت است.
