راهنمای قرار دادن فونت IranYekan

این پوشه شامل فایل فونت IranYekan نیست و به دلیل مسائل مجوز در مخزن قرار ندارد.

برای فعال‌سازی فونت در پنل ادمین:

1. فایل‌های فونت IranYekan را به‌صورت قانونی تهیه کنید. نمونه نام فایل‌های پیشنهادی:
   - IranYekan.woff2
   - IranYekan.woff
   - IranYekan-Bold.woff2
   - IranYekan-Bold.woff

2. فایل‌های بالا را در این پوشه قرار دهید (`public/fonts/IranYekan/`).

3. در صورتی که سرور توسعه (`npm run dev`) در حال اجرا است، صفحه را رفرش کنید تا فونت جدید بارگذاری شود. در غیر این صورت سرور را مجددا راه‌اندازی کنید.

دقت: فقط از منابع قانونی یا نسخه‌های خریداری‌شده فونت استفاده کنید.
